# UT Reader

UT Reader is a utility project for reading and processing UT-related data/files.

> **Status:** This project is still in active development. The code, behaviour, supported file formats, command-line options, and documentation may change while the project is being built and tested.

## Project Description

UT Reader is intended to provide a simple way to inspect, parse, and work with UT data in a more readable or usable form.

The project is currently at an early stage, so this README describes the intended purpose and expected direction of the project rather than a final stable release.

## Current Purpose

The script/project is being developed to:

- Read UT-related input files or data sources.
- Parse useful information from the source data.
- Present the parsed information in a clearer format.
- Help with testing, inspection, or conversion workflows.
- Provide a base for future improvements as the format and use case are refined.
