## Epic source, precise branch ordering

Pinned Epic UE5.8.3 `Engine/Source/Runtime/CoreUObject/Private/Serialization/AsyncLoading2.cpp`, SHA256 `43ce5d7838d25f5b1a39f3acd5db71e29973c5a0f5f28240ef7602d309d616a9`.

1. `FGlobalImportStore::FindScriptImportObject` (2604) asserts a typed ScriptImport and executes **`ScriptObjects.FindRef(GlobalIndex)`** against the **live map**. It does not consult the global cooked ScriptObjects chunk.
2. `FPackageImportStore::GetImportObject` (2825) sends typed ScriptImport to that live lookup. PackageImport branches into a **different public-export-key lookup** (and editor redirector logic); a match on the numerical 62-bit value cannot substitute.
3. `FPackageImportStore::GetImportName` (2852) first calls `GetImportObject`. If a live UObject exists, returns **`Import->GetFName().ToString()`**. Only if null, and only under compiled **`ALT2_ENABLE_SCRIPT_IMPORTS_DEBUGGING`**, a ScriptImport can return `CookedScriptObjectsDebug.GetPathName(GlobalIndex)`. Otherwise the result is an empty string. The fallback string is for diagnostic logs, **not dependency resolution**.
4. `FCookedScriptObjectsDebug` registers a cooked-only delegate if `RequiresCookedData()`. `OnCompiledInUObjectsRegistered` loads the optional ScriptObjects chunk **only in the PreCDO phase and if `GEnableScriptImportsDebugging`**; the delegate is then removed. Its pre-CDO load is distinct from the eventual `RegistrationComplete`.
5. `RegistrationComplete` calls `TrimDebugData(ScriptObjects)` when compiled-in debugging is present. The trim marks every cooked record whose typed global index is **already live** for removal, but recursively **retains cooked outers** required to reconstruct paths for *missing* script entries. If all are live, the diagnostics map becomes empty.
6. `GetPathNameInternal` follows retained cooked outer indices; the separator after the first ancestor is `.`, then `SUBOBJECT_DELIMITER_CHAR` (**`:`**), then `?` for deeper ancestors where `.` versus `:` cannot be established. An unknown index returns an empty name. The resulting string remains offline evidence, not proof of registration.
