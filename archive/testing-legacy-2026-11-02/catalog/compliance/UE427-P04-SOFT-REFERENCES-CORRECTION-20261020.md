# UE4.27.2 — confirmed Epic source mismatch in soft package references (P04 finding)

**Before:** complete genuine UE4.27 Engine/Content corpus of 1,749 `.uasset`/`.umap` files yielded two reader errors: `WorldGridMaterial_Low.uasset` and `VivePreControllerMaterial_Inst.uasset`, both `Could not parse string asset references map: bad FString length=...`. Despite valid name/import/export table counts, the UnrealDB reader consumed **FName + FString** for `version >= 514` and an FString for older versions.

**Pinned Epic evidence:** `Engine/Source/Runtime/CoreUObject/Private/UObject/SavePackage.cpp` around lines 3742–3753 and `SavePackage2.cpp` around lines 1411–1417 always serialize `SoftPackageReferenceList` entries as **FName** (`SoftReferenceStream.EnterElement() << SoftPackageName`). `FName` consumes two 32-bit words (index, number) when serialized in the package linker, not an asset path and separate subpath string. The erroneous rule confused UE4's `FSoftObjectPath` property format with the summary's soft-package reference table.

**Fix:** `UE4/UnrealPackageReader.php::readStringAssetReferences()` now consumes one FName per entry for all supported source versions. Minimum reference-table entry width in `validateSummaryBounds()` is 8 bytes. `verify-ue4-427-reader-contract.php` now guards the correct source distinction rather than asserting the old wrong layout. A repeatable full real corpus verifier `catalog/bin/verify-ue427-real-reader-table-corpus.php` verifies exact decoded name/import/export counts, reader issues and summary variants.

**After:** 1,749/1,749 genuine installed UE4.27 Engine/Content assets parse with **zero reader errors**; 108,582 names, 20,207 imports, 37,552 exports, 2,271 custom-version entries, 112 decoded soft-package reference entries, six legacy marker versions (-2 through -7). Source-shaped reader contract exits 0. No production MySQL modifications. This is a confirmed P04 finding resolved during corpus stress verification, but does **not** certify P04's unrelated DependsMap/preload branches and does **not** by itself certify all of P01–P10.
