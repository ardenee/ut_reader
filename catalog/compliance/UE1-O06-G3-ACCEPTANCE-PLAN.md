## Source scope and acceptance principle

G3 certifies **classic UE1 class/field/property serialization and native loaded-field behavior** through the original relevant Epic source, not merely a plausible PHP byte decoder.

- **C98:** Unreal v1.200 (May 1998), canonical `L:/Source/Games/Unreal/Unreal [v1.200] [1998-05-19]/Core/Src/UnClass.cpp` and `UnProp.cpp`, original headers, source-selected versions and inheritance.
- **T99:** UT99 v432 supersedes v400 as the ONE target; v432 `Core/Inc` declarations and stock compiled Core.dll/Engine.dll are authoritative where v432 sources are absent. The earlier UT99 v400 `Core/Src/UnClass.cpp` and `UnProp.cpp` are implementation authority only after verifying the compiled v432 behavior/unchanged branch. G5's eight accepted selected source profiles are SHA-reused; they do not automatically accept all G3 classes/versions.
- **C227:** Unreal v1.227: canonical tree `L:/Source/Games/Unreal/Unreal [v1.227]/Core` currently contains `Classes` and `Inc`, **not `Src/UnClass.cpp` or `Src/UnProp.cpp`**. Existing C227 register entries are five **Emitter** serializers, not the missing Core class/property methods. This is a **blocking source/oracle discovery requirement for G3**, not evidence that v1.227 uses v1.200 or UT99 methods. Obtain legitimate implementation C++ or compiled v227 Core native/PDB disassembly and prove each applicable inherited behavior; if neither is available, keep affected tests BLOCKED. Do not guess source lineage from overlapping package version 69.
- The canonical `UE1-O06-SERIALIZER-REGISTER.json` contains **14 C98 and 18 T99 currently registered class/property method entries** (32 mapped records); the missing v227 Core source/mapping coverage is an explicit gap. The attached machine matrix lists all 32 records and two required C227 discovery prerequisites. Do **not** assume 32 entries means full method coverage: original Core headers/symbols must be independently enumerated before G3-02 passes.
- Preserve independent version-specific boundaries (C98 v34–61 where supported by original source; UT99 v60–69 as supported by original v432 compiled loader; C227 v60–69 only where validated against actual source/compiled engine). Treat per-profile limits as source conditions, not rejection heuristics.
