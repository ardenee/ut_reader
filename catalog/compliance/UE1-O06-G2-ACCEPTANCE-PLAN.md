# UE1 O06 G2 — Fixed acceptance test plan (PRE-EXECUTION)

**State:** PLANNED, NOT TESTED OR ACCEPTED by this document. **Scope:** build-selected May 1997 Unreal v0.86x (U86) and July 1997 Unreal v0.867 (U97), original Unrealfile archive versions 22/23. Both builds may use version 23; package version cannot identify the source lineage. This plan freezes required G2 source-contract tests before implementation or gate runs. G5 runtime/native original-game loaded-value certification, C98/C227 classic UE1, and O10 runtime linking are independent.

## Inventory and freeze rules

- Canonical class list: `catalog/compliance/UE1-O06-SERIALIZER-REGISTER.json`. Exactly **49 May + 49 July registrations**: **43 MAPPED + 6 source-confirmed EXCLUDED in each build**. **86 mapped class/source pairs + 12 exclusion decisions**. MAPPED means an implementation route exists; it is not a passing source contract.
- Machine-auditable per-class assignment and current test filenames: `UE1-O06-G2-ACCEPTANCE-MATRIX.json`, generated from the canonical register. Every U86/U97 entry MUST be assigned to exactly one source serializer group and have an existing test candidate; the final verifier must fail on new, missing, unclassified or incorrectly excluded registrations.
- Original source authority: `L:/Source/Games/Unreal/Unreal [v0.86x] [1997-05-25]/Src` and `L:/Source/Games/Unreal/Unreal [v0.867] [1997-07-25]/Src`, including both original `Engine.dsp` build-selected translation-unit lists. May's unbuilt duplicate `Engine/UnRes.cpp` is NOT a serialization authority when `Engine/UnObj.cpp` is selected.
- Proof must distinguish `SerializeHeader`, `SerializeData`, `SerializeBin`, `FProperty::SerializeProperty`, persistent record `operator<<`, script expression/archive memory offsets, parent-class dispatch and source-defined exclusions. Every tested output must include actual consumed archive bytes/EOF and parsed values, not just “reader did not throw.”
- For each materially distinct source branch, specify both build and archive version applicability; positive, boundary and malformed fixtures; exact native source version gate; and one independent source-derived expected value/byte sequence. Only reuse another branch's fixture if the two **build-selected original C++ serializer bodies and relevant flags are source-proven equivalent**.
- The FINAL G2 gate is **one consolidated decision** after source coverage and distinct branch acceptance are complete. No repeated partial tests to seek progress. Reuse SHA-pinned PASS if unchanged, and preserve every failure. No tests on PRD: DEV executes checks; PRD receives only verified deployment artifacts with SHA-256 comparisons.

## Reuse and stop conditions

Current preflight observed **30 existing directly G2-relevant scripts** (24 `verify-ue1-original-unrealfile-*.php`, 4 `verify-ue1-o06-g2-*.php`, 2 `verify-ue1-o06-1997-*.php`), of which **29 have an existing journalled PASS and an unchanged test-file SHA**. `verify-ue1-original-unrealfile-metadata.php` has no reuse-ready PASS in the central journal. These are *candidate fixtures*, not 29 completed G2 acceptance contracts: the final source/reader/transitive input hashes and May/July scope must still be checked. Historical PRD tests may be recorded, but **new tests run DEV only**. No G2 tests were run to write this plan.

For each ID: `PLANNED -> SOURCE_VERIFIED -> PASS`, or one explicit `BLOCKED` (missing source/oracle) / `FAILED` (actual divergence) with exact source function and next production fix. Once an ID has one current complete PASS, **stop testing it**, reuse its SHA and move on. Do not expand the 18-contract list just to add test volume; only amend with an identified Epic source branch missing from this inventory, with a written reason before testing.

G2 is ACCEPTED only when every applicable contract G2-01..G2-18 passes, all 98 registration/source dispositions remain reconciled, all required source-specific saved-file behavior is implemented, and the independent gate driver signs off. **G2 source acceptance does NOT certify G5 genuine stock compiled loaded values or O10 runtime linking.**
