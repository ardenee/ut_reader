# UE4.27.2 P01 — source-defined compression flags/chunks rejection

**Confirmed difference:** `UE4/UnrealPackageReader.php` used to read `CompressionFlags` and legacy `CompressedChunks` without enforcing Epic's UE4.27 loader gates. In the pinned `Engine/Source/Runtime/CoreUObject/Private/UObject/PackageFileSummary.cpp` after SavedBy/CompatibleWithEngineVersion, the source calls `FCompression::VerifyCompressionFlagsValid()` and returns on invalid flags. Source `Core/Private/Misc/Compression.cpp` permits only `COMPRESS_DeprecatedFormatFlagsMask | COMPRESS_OptionsFlagsMask`, both defined in `CompressionFlags.h` (`0x0F | 0xF0 = 0xFF`). The same summary loader returns early for `CompressedChunks.Num() > 0`, because old whole-package-compressed assets are not supported.

**Production fix:** reader now rejects any `CompressionFlags` bit outside `0xFF` and nonempty legacy `CompressedChunks` immediately after reading each field, before consuming other summary fields. The original on-disk `compressionFlags` and decoded `compressedChunks` remain available in the partially decoded header for diagnostics.

**Acceptance:** `verify-uedb5-ut4-persistence.php` builds source-shaped negative fixtures with flag `0x100` and a nonempty one-row compressed chunks array, asserts rejection of both and accepts a normal source-conforming v510 fixture; also asserts DependsMap preservation and clean-master v511 policy. All assertions passed. `verify-ue427-real-reader-table-corpus.php` then parsed **1,749/1,749** authentic installed UE4.27 assets with zero reader errors; 1,748 dependency maps and 91,218 references retained. These checks validate source branch outcomes but are not a separately compiled Epic native summary oracle; P01 remains open pending that differential and editor-only unversioned cases. No production SQL writes.
