# P04 — Zen import/export/dependency and optional-segment source reconciliation

Epic UE5.8.3 pinned `Engine/Source/Runtime/CoreUObject/Private/Serialization/AsyncLoading2.cpp`: `InitializeAsyncPackageFromPackageStore`, `ImportPackagesRecursiveInner`, `Event_ProcessDependencies`, `ProcessExportDependencies`, `GetPublicExportIndex`, `EventDrivenIndexToObject`. Production `Uedb5ZenPackageReader.php`, `Uedb5Ue5ZenIoStoreSnapshotBuilder.php`, `Uedb5MigrationValidator.php`.

**Source-defined production correction:** Epic `FAsyncPackage2::ProcessExportDependencies` returns without reading the entry counts whenever `DependencyBundle.FirstEntryIndex < 0`. UnrealDB `validateDependencyRanges` had rejected `FirstEntryIndex=-1` with nonzero counts and any value less than -1, imposing a gate absent from Epic. It now skips all negative first indices and continues bounds checking for nonnegative ranges. A serialized synthetic Zen header with FirstEntryIndex=-2 and nonzero counts exercises this branch; it fails with the prior implementation and passes with this correction. A separate positive-index out-of-range rejection remains.

Other primary branch coverage: authoritative imported package IDs from PackageStore, separate editor optional-segment imported IDs/header, ordinary and optional export maps, public export hashes, dependency bundle Create/Serialize partitions, and package-store redirect/localization persistence. Existing P04 verifiers include `verify-uedb5-ue5-zen-package.php`, `verify-uedb5-ue5-zen-dependency-resolution.php`, `verify-uedb5-zen-object-index-source-oracle.php`, `verify-uedb5-zen-dependency-partitions.php`, and B004/B012 acceptance. All passed after updating the prior over-strict negative-index test.

**Scope and remaining blocker:** UnrealDB is a format/metadata reader and publisher, not Epic's live `UObject` loader. Executing object creation, editor instancing, runtime texture/shader load and live package redirects is outside its persisted metadata role; source-defined identities and dependency edges are the relevant scope. The Epic-produced native **decoded per-row Zen semantic oracle** remains unavailable, though prior retained IoStore chunk byte parity covered 27,240 real packages. SRC-004 stays partial pending that oracle or a precise certification limitation. Secondary S001 is deferred after P11 per the fixed plan.
