# UnrealDB development contract

The objective is **serialized Unreal file behavior identical to the selected Epic source**. Passing UnrealDB's own synthetic tests is not proof of parity.

**UT99 baseline rule:** UT99 v432 supersedes v400 as ONE game-source target. Retain v400 implementations only as inherited archive source where v432 lacks published Core/Engine serializer bodies; compare v432 declarations and compiled behavior before claiming parity. The source folder is labelled v432 but specifies ENGINE_VERSION 430 and package version 69. The v432 USkeletalMesh/UAnimation native archive methods are mapped from compiled Engine.dll, but genuine G5 loaded-value parity and inherited v400 behavior remain OPEN. See specs/engine-game-source-precedence.md.


**Chronological cumulative Unreal source rule (2026-10-27):** Original Unreal game revisions are v0.82 -> v0.83 -> v0.84a -> v0.86x -> v0.867 -> v1.200 -> v1.224 -> v1.227. A game-source change introduced at v0.84a persists into each later revision until a later source explicitly replaces/removes that SAME applicable serializer operation. A missing later method source is inheritance, not a reset and not a requirement to obtain a matching Core.lib. Use UE1 engine as baseline, apply game-specific changes chronologically and persist each one. A new class, changed header, or inline method does constitute source change requiring investigation; missing cpp by itself does not. Source format boundaries (1996 native-resource, 1997 Unrealfile, classic post-1998 .u package) are actual serializer replacements, not license to copy obsolete wire formats unchanged. UT99 v432 inherits its own v400 baseline when absent, never Unreal v227 behavior.

**UT99 469f explicit-source overlay (2026-10-27):** Actual user-provided OldUnreal 469f SDK/runtime adds UPointerProperty to historical UT99 v432, using inherited UProperty::Serialize. UT99 cumulative source chain is UE1 engine -> v400 -> v432 -> 469f; changes carry forward until overridden. Both versions can have v69/licensee0 and cannot be distinguished from package version: require explicit ut99-v469f provenance. Overlay inherits UT99 v432 archive methods and grants new 469f classes only where actual 469f source/compiled evidence supports them. Source and SHA archive: catalog/compliance/UE1-O06-G3-T99-469F-MATCHED-SDK-POINTER-REA.json.

**Engine-source-before-game-source rule (UE1–UE5):** Implement the build-selected Epic engine serializer first, then compose only source-proven overrides from the specific game/loader. An archive package version does **not** identify its game (e.g. Unreal v1.227 is not UT99 even when both use version 69). Preserve independent engine, game, loader and licensee provenance through nested readers. Never borrow another game's serializer as a fallback for an unresolved lineage. Follow [specs/engine-game-source-precedence.md](specs/engine-game-source-precedence.md) for all future work.
